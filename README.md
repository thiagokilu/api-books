# api-books

- [] RF01: O usuário deve conseguir criar uma conta.
- [] RF02: O usuário deve conseguir fazer login.
- [] RF03: O sistema deve enviar um e-mail de confirmação de conta após o cadastro (via Resend).
- [] RF04: O usuário deve confirmar seu e-mail antes de acessar funcionalidades da estante.
- [] RF05: O usuário deve conseguir solicitar redefinição de senha por e-mail (via Resend).
- [] RF06: O usuário deve conseguir redefinir sua senha a partir do link recebido por e-mail.
- [] RF07: O usuário deve conseguir pesquisar livros por título ou autor.
- [] RF08: O usuário deve conseguir adicionar um livro à sua estante.
- [] RF09: O usuário deve conseguir remover um livro da sua estante.
- [] RF10: O usuário deve conseguir alterar o status de leitura.
- [] RF11: O usuário deve conseguir atualizar seu progresso de leitura.
- [] RF12: O sistema deve calcular o percentual de leitura automaticamente.
- [] RF13: O sistema deve exibir um resumo da estante no dashboard.
- [] RF14: O usuário deve conseguir editar seus dados de perfil.

- [] RNF01: A aplicação deve ser responsiva.
- [] RNF02: Os dados de cada usuário devem ser protegidos, com senhas armazenadas via hash (bcrypt ou argon2) e autenticação via JWT.
- [] RNF03: A API deve retornar mensagens de erro padronizadas, no formato { error: { code, message } }.
- [] RNF04: O projeto deve possuir testes automatizados (unitários e/ou de integração) e documentação da API via Swagger/OpenAPI.
